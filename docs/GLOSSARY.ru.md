# Глоссарий SEJIRE

| Термин | Значение |
|--------|----------|
| **Commit** | Неизменяемый снимок (snapshot) древа + метаданные версии |
| **HEAD** | Указатель на последний commit |
| **Snapshot** | Полное состояние `persons` на момент commit |
| **Tombstone** | Флаг «персона снята в этой версии»; история сохраняется |
| **Tree Process** | AO-актор одного семейного древа |
| **Factory Process** | AO-актор, порождающий Tree Process |
| **Holographic state** | Состояние, восстановимое из лога сообщений на Arweave |
| **HyperBEAM** | Прод-реализация AO-Core с HTTP-доступом к state |
| **ArNS** | Человекочитаемые имена permaweb (`name.ar.io`) |
| **Media ref** | Ссылка `{ tx, kind }` на блоб в Arweave, не сам файл |
| **Draft** | Локальные незафиксированные правки клиента |
| **Owner** | Адрес с правом Commit / ACL |
| **Endowment** | Модель разовой оплаты хранения на Arweave |
| **Parent_TX / parent_commit_id** | Ссылка на предыдущую версию (git-родитель) |
| **Digital granite** | Текстовый граф фактов как долговечный слой протокола |
