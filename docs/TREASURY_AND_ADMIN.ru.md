# Казна и админка SEJIRE

Казна — отдельный кошелёк **проекта**. Им оплачивается сеть за чужие зашифрованные сейфы. Это **не** 12 слов пользователя.

Сейчас весь контур на GitHub Pages. Потом тот же экран кассы переедет на `https://sejire.ar.io`.

## Ссылка (сейчас)

https://azovskaya.github.io/Sejire_arweave/#/admin

Тихая ссылка «Касса» — в меню после слова SEJIRE.

## Как проверить контур

1. Откройте кассу, задайте пароль (от 12 символов).
2. Вкладка **Ключи** → «Создать казну здесь» (или вставить уже существующий JWK).
3. JSON покажется **один раз** — в 1Password и на флешку. На бумагу — только адрес.
4. На адрес казны пополните AR (Binance → сеть Arweave).
5. На сайте: новое древо → Сохранить → казна платит сеть. 12 слов только шифруют сейф.
6. «Открыть по 12 словам» — древо должно найтись в Arweave.
7. Снова касса: в обзоре время и число сохранений (после индексации сети, обычно минуты). Казну можно сменить.

Ключи лежат **в этом браузере** (пароль + казна). Другой компьютер — снова ввести. Имена и 12 слов в кассу не попадают.

**Нельзя:** git, Slack, почта, чат с агентом.

Пока нет ИП/Kaspi, сохранения идут из казны напрямую. Mock + живая казна на будущем Worker по-прежнему запрещены; на Pages это тестовый контур.
