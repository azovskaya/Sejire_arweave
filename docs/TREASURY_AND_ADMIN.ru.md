# Казна и админка SEJIRE

Казна — отдельный кошелёк **проекта**. Им оплачивается сеть за чужие зашифрованные сейфы после Kaspi. Это **не** 12 слов пользователя и не личный кошелёк.

Ключи, токен Kaspi и пароль админки прописываются **на странице** `/admin` после деплоя кассира. В чат агенту их не слать.

Агент ключ не создаёт: если сделать казну в облаке Cursor, файл пропадёт вместе с машиной.

## Порядок (на своём Mac)

```bash
cd apps/sponsor
npx wrangler login
npx wrangler kv namespace create IDEMPOTENCY
# id прописать в wrangler.toml (раскомментировать [[kv_namespaces]])
npx wrangler deploy
```

По желанию в `[vars]` wrangler.toml:

```
SETUP_PIN = "пин только на первый вход"
```

Так чужой человек не заберёт пустой Worker, пока вы ещё не задали пароль.

Откройте `https://<worker>.workers.dev/admin`:

1. Задайте пароль админки (от 12 символов). Если ставили `SETUP_PIN` — введите его один раз.
2. Вкладка **Ключи**:
   - «Создать казну здесь» **или** вставить уже существующий JWK;
   - JSON казны покажется **один раз** — сразу в 1Password и на флешку;
   - на бумагу — только **адрес**;
   - токен Kaspi, Trade Point, цена, mock/kaspi.
3. Пустое поле при сохранении = «не менять». Секреты с экрана больше не читаются.

Пока нет ИП/Kaspi: путь оплаты `mock`. Mock **нельзя** держать вместе с живой казной — кассир так откажется работать.

На обзоре: сколько древ, сколько сохранений, оплаты, **время** появления каждого древа. Имена, 12 слов, содержимое сейфа — нет.

### Куда сохранить казну, чтобы не потерять доступ

| Место | Что лежит |
|--------|-----------|
| 1Password / Bitwarden | весь JWK (тот JSON, что админка показала один раз) |
| Зашифрованная флешка или сейф | копия того же JSON |
| Бумага | только **адрес** казны (не JSON) |

Три копии. Если JSON исчезнет — из казны больше нельзя подписать загрузки. Cloudflare KV — рабочая копия для кассира, не единственное хранилище.

**Нельзя:** git, Slack, почта, чат с агентом.

### Запасной путь без админки

Если Worker ещё не задеплоен, казну можно создать файлом на своём компьютере:

```bash
cd путь/к/Sejire_arweave
npm install --prefix apps/sponsor
npm run treasury:init
```

Появится **`treasury.local.json`** (в git не попадает). Потом вставьте `jwk` во вкладку «Ключи», а не в `wrangler secret put`.

### GitHub

Settings → Secrets → Actions: ключ **сайта** для деплоя permaweb, если пользуетесь Actions. Это не замена 1Password и не ключи кассира.

### Пополнить казну AR

На адрес, который показала админка (Binance → вывод AR → сеть Arweave). Сколько держать на горячем кошельке — отдельно; это не 12 слов людей.
