# SEJIRE — сравнение с рынком

Актуально на 2026-07-27. Для инвестора / презентации.

## Короткий вердикт

| | Ancestry / MyHeritage | DeepFamily | SEJIRE |
|--|----------------------|------------|--------|
| Живой массовый продукт | да | ранний протокол / сайт | MVP есть (Pages + publish) |
| Децентрализация данных | нет | частично (EVM) | да (Arweave + seed) |
| «Заплатил раз — на 200+ лет» | нет (подписка) | нет (газ / сеть EVM) | да (endowment Arweave) |
| Без крипто-кошелька у пользователя | да | нет (нужен EVM-кошелёк) | цель: карта $3 «под капотом» |
| Шежіре / жеті ата | нет | нет | да (продуктовый фокус) |
| Прямой конкурент на Arweave | — | нет | ниша почти пустая |

**Итог:** на Arweave/permaweb готового живого аналога SEJIRE нет. DeepFamily — ближайшая *идея* децентрализованного древа, но другой стек и UX. Ancestry/MyHeritage — лидеры рынка, но централизованные и подписочные.

## Подробная таблица

| Параметр | Ancestry / MyHeritage | DeepFamily | SEJIRE |
|----------|----------------------|------------|--------|

| Культурный фокус | Западный рынок | Универсальный / crypto-native | Казахское **шежіре / жеті ата** |
| Бизнес-модель | Подписка + ДНК | Токен / endorsement / NFT | Разовый fiat ($3) + казна Turbo |
| Статус на Arweave | — | не на Arweave | Целевой стек: Arweave + (план) ArNS |
| Ссылка | ancestry.com / myheritage.com | [deepfamily.org](https://deepfamily.org/) | [github.io demo](https://azovskaya.github.io/Sejire_arweave/) |

## Позиционирование одной фразой

- **Ancestry/MyHeritage** — удобно сейчас, но ваши предки живут на сервере чужой компании.  
- **DeepFamily** — крипто-протокол отношений и NFT-био, другой вход и другая сеть.  
- **SEJIRE** — семейная память как **вечный зашифрованный артефакт**: шежіре, 12 слов, Arweave, без покупки токенов пользователем.

## Слайд (готовые формулировки)

**Заголовок:** Почему SEJIRE, а не Ancestry и не DeepFamily  

**Три колонки:**
1. Ancestry — подписка и lock-in  
2. DeepFamily — кошелёк и EVM  
3. SEJIRE — карта + 12 слов + 200+ лет на Arweave  

См. также слайд «Сравнение» в `presentation/index.html`.
