# Flow 09 — Pedigree UX (как у лидеров рынка)

Взято лучшее у MyHeritage / FamilySearch / Ancestry:

1. **Pedigree в центре экрана** — не формы, а схема рода
2. **Add-Me cards** — «Добавить маму / папу» прямо на пустых местах
3. **Панель профиля** справа — клик по человеку → факты, +родственники
4. **Pan / zoom** по холсту
5. **Начать с себя** → дальше предки вверх по поколениям
6. **12 слов** только на публикации в Arweave

Код: `PedigreeView`, `PersonPanel`, `AddPersonModal`, `lib/pedigree.ts`
