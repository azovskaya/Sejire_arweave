# Flow 03 — Просмотр истории

## Цель

Открыть любое прошлое состояние древа без возможности «тихо» его изменить.

## Шаги

1. `History` → список версий
2. Пользователь выбирает `commit_id`
3. `GetCommit(Commit-Id)` → snapshot
4. UI переходит в **read-only historical mode**
5. Banner: «Просмотр vN»; редактирование отключено

## Продолжение от старой версии

Если пользователь хочет править от vK:

1. Загрузить snapshot vK в draft (`loadDraftFromCommit`)
2. Пометить dirty
3. Следующий Commit создаёт **новую** версию от **текущего HEAD** (v1 linear)  
   либо (будущее) ветку — не в v1.

Важно: «взять как основу» ≠ переписать vK.

## Diff UX

Client MAY вычислить `diffPersonIds(old, head)` для подсветки +/~/-.
