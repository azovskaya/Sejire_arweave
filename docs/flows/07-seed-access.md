# Flow 07 — Когда нужны 12 слов

## Новая последовательность (продукт)

1. **Открыть протокол** → сразу создать древо предков (без seed)
2. Проводник: **я → мама → папа → бабушки/дедушки**
3. Свободно дополнять род, фиксировать локальные версии
4. Кнопка **«Отправить в Arweave»** → только здесь:
   - создать/ввести 12 слов
   - зашифровать сейф
   - опубликовать / скачать envelope
5. Позже с другого устройства: «Открыть по 12 словам»

## Зачем так

Сбор семьи не должен упираться в крипто-онбординг.  
BIP-39 — ключ к **вечной публикации**, не к черновику.

Спека деривации: [`docs/security/SEED_ACCESS.md`](../security/SEED_ACCESS.md)

## Открыть уже сохранённое — без централизации

После того как сейф уже лежит в Arweave, **повторное открытие не требует** Kaspi, Stripe, Cloudflare и аккаунта SEJIRE.

1. Открыть приложение (канон: `sejire.ar.io`).
2. Ввести 12 слов.
3. Клиент считает `vaultId` + ключ шифрования.
4. GraphQL / поиск по тегу `Vault-Id` через шлюз Arweave — **список версий** (HEIGHT_DESC).
5. Пользователь выбирает версию (если их больше одной) → скачать envelope → расшифровать на устройстве.
6. Правки + повторное «Сохранить» теми же словами = **новая** версия (новая оплата); прошлые TX читаемы.

Зафиксировано в [`LOCKED_DECISIONS.ru.md`](../LOCKED_DECISIONS.ru.md) §4.
