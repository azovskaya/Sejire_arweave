# Flow 08 — Проводник сбора рода

## Порядок

1. Я (корень)
2. Мама → привязывается родителем ко «мне»
3. Папа → второй родитель
4. Бабушка/дедушка по маме → родители мамы
5. Бабушка/дедушка по папе → родители папы
6. Свободный режим + локальные commits
7. Отправка в Arweave (flow 07)

Код: `apps/web/src/lib/guide.ts`, UI: `Workspace` guide-card.
