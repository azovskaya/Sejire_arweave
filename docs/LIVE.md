## Открыть и строить древо прямо сейчас

**Основная ссылка (CDN с ветки `gh-pages`):**  
https://cdn.jsdelivr.net/gh/azovskaya/Sejire_arweave@gh-pages/index.html

Зеркало:  
https://raw.githack.com/azovskaya/Sejire_arweave/gh-pages/index.html

### Как начать
1. Откройте ссылку  
2. «Создать новый сейф» → **запишите 12 слов**  
3. Создайте древо → добавляйте людей → «Зафиксировать версию»  
4. Для другого устройства: «Экспорт» или «В вечность» (нужен AR)

## Постоянный домен GitHub Pages (рекомендуется включить владельцу)

Ветка `gh-pages` уже запушена. В настройках репозитория:

**Settings → Pages → Branch: `gh-pages` / root → Save**

После включения постоянный адрес будет:  
https://azovskaya.github.io/Sejire_arweave/

Workflow: `.github/workflows/pages.yml` (после включения Pages + permissions).
